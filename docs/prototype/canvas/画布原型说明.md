## 两套原型的关系

`docs/prototype/` 下现在有两套五屏原型。它们**不是同一件东西的两种格式**，
权威性也不同：

|                  | `../svg/` + `../shots/`         | 本目录（`canvas/`）                        |
| ---------------- | ------------------------------- | ------------------------------------------ |
| 怎么来的         | 从**真实运行的界面**用 CDP 量出来 | 在 pen.dev 画布上**手绘**                   |
| 相当于代码的什么 | 代码的**镜像**                    | 代码的**设计稿**（先有它，后有代码）        |
| 过期了看得出来吗 | 和真实界面对不上就是过期了        | 对不上**未必**是它错 —— 但它错了也看不出来 |
| 权威性           | 高                               | **低**                                      |

**冲突时一律以代码为准。**

这不是一句套话。本次改版前后撞到过两次：

- **B5 的「高级」区原本画错了。** 画布上它是「3 行只读映射 + 一个『添加规则』按钮」，
  而真实控件是一个 `<textarea>`（`scripts/smoke.js` 明文断言它必须存在且回显非空）。
  归档前已按代码改正 —— 现在图上的才是对的。
- **B4 的正文比真实界面高。** 多了一行脚本的临时路径、说明文字也没按真实界面分行，
  于是底部那段 `.hint` 被操作栏裁掉了半行；而真实界面的同一个弹窗是**放得下**的
  （CDP 几何断言里就有一条钉着「确认接管完整落在首屏内」）。
  **这一处没有改**，保留画布原样归档 —— 见下面「已知与代码不符的地方」。

## 为什么 PNG 和 `.pen` 都存

- **PNG** —— 给人看的。放文档、贴 issue、和 `../shots/` 并排比对，不需要装任何东西。
- **`.pen`** —— 给 pen.dev 载入的。留着它是因为：

> **归档时发现 pen.dev 并没有持久化这张画布。**
> 磁盘上的 `~/.pencil/documents/b2dc7506-6f68-4cb1-9aa5-4b1f75042947/pencil-new.pen`
> 只有 **259 字节** —— 那是一个空的默认白框。B1–B5 全部只活在 pen.dev 进程的内存里，
> **应用一退出就没了。**

所以本目录里这一份 `.pen` 是目前**唯一**的落盘副本。

### 它是怎么来的

用 pencil MCP 把每屏的 schema 读出来、连同文档变量一起重新拼成一个文档：

```js
Export(["tm46X", "YkW2Y", "KBOqc", "t7A56", "Fs8eP"], "png", "<输出目录>");

const ids = ["tm46X", "YkW2Y", "KBOqc", "t7A56", "Fs8eP"];
Print(
  JSON.stringify({ version: "2.6", variables: GetVariables().variables, children: ids.map(Get) })
);
```

顶层结构 `{version, variables, children}` 是照着 pen.dev 自己的文档
（`pencil-lunaris.pen` / `pencil-shadcn.pen` / `pencil-nitro.pen`）核对的 —— 它们的顶层键正是这四个
（无变量时省略后两个）。节点字段则来自 `Get` 的返回值，`execute` 文档明确保证它能
「round-trips straight into `Insert`/`Copy`/`Update`/`Replace`」。

**但没能实测载入** —— pencil MCP 只能操作当前活动文档，没有「打开另一个文档」的入口。
理论上结构是对的，第一次载入时请留意。

### 这一份不是一键脚本

`../svg/` 那套有 `scripts/export-svg.js`，改完界面重跑就行。
本目录**没有对应的脚本**：它需要 pen.dev 应用开着、且 pencil MCP 在场。
`Export` 产出的文件名是**节点 id**（`tm46X.png`），要自己改名成本目录的命名。

## 怎么打开 `.pen`

装 pen.dev（VSCode 扩展 `highagency.pencildev`），在它里面打开
`cc-nbproject-原型.pen`。5 屏会依次排开，可拖可改。

配合 `../geom/*.json` 用：那里有真实界面的坐标、尺寸、颜色、字号、文案（DOM 实测值），
是这个界面**实际长什么样**的唯一权威来源。
