# 高保真原型（SVG）

> 一套 5 张、每个元素都能拖能改的矢量原型图。
> 图是**从真实界面导出来的**，不是照着截图重画的。
>
> 生成于 2026-09-29

---

## 为什么是 SVG，不是 `.rp` / `.mp` / `.mrp`

原计划是生成一个能导入原型工具的文件，让用户在里面拖。三条路都试过，全部堵死：

| 路线                        | 卡在哪                                                                                                     |
| --------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Axure `.rp`                 | 专有二进制，**没有写 API**；官方 `Axure.Document.dll` 是只读的，且限定 Windows + RP 8/9                    |
| Axure HTML 导入（`.zip`）   | 导入器要求导出包带 `data/document.js`；GitHub / Gitee 上找到的 7 个「Axure 原型」仓库全是单文件 HTML 伪原型 |
| Mockplus Classic `.mp`      | 已停止维护，macOS 13.4.1 起就不兼容（本机 macOS 26.3.1 / arm64）                                            |
| 摹客 RP `.mrp`              | 格式未公开；官方 REST API 只有 `preview` 两个只读端点，**没有创建 / 导入的写接口**；网页版是 Canvas 应用，CDP 驱动不了 |

所以「我生成文件 → 你导入 → 得到可拖元件」这条路走不通。

**换成 SVG 的收益**：SVG 拖进 Figma（免费网页版即可）会被**逐层还原成可编辑矢量图层** ——
文本能改字、矩形能拖能改色、图标是矢量路径。比摹客那套更接近「自己拖着改」这个诉求。

## 这 5 张图是什么

| 文件                       | 界面           | 说明                                               |
| -------------------------- | -------------- | -------------------------------------------------- |
| `svg/01-providers.svg`     | 供应商列表     | 三个供应商，DeepSeek 为激活态（紫竖条 + 渐变底色） |
| `svg/02-logs.svg`          | 日志（空态）   | 无记录时的虚线空状态框                             |
| `svg/03-usage.svg`         | 用量（空态）   | 三张统计卡 + 时间范围选择器 + 空状态               |
| `svg/04-setup-modal.svg`   | 接管弹窗       | 三段式布局、风险告警、三行改动对照表               |
| `svg/05-profile-modal.svg` | 供应商编辑弹窗 | 三个输入框（API Key 已还原成圆点）                 |

配套产物：

- `shots/*.png` —— 同一批界面的真实截图，用来对照。**改了 SVG 之后拿它比对，肉眼就能看出差在哪**
- `geom/*.json` —— 中间数据。每个元素的坐标、尺寸、颜色、字号、文案，精确到小数点后两位

`import-test/a-plain/` 是当初试导入用的探针，与现在这套无关，留着是因为删东西要单独确认。

## 怎么用

1. 打开 [figma.com](https://figma.com)（免费版够用，不用装桌面端）
2. 新建文件 → 把 `svg/01-providers.svg` **直接拖进画布**
3. Figma 会问「作为图层导入还是作为图片」—— 选**图层**
4. 每个矩形、每行文字、每个图标都是独立图层，可以拖、可以改字、可以调色

> 一次拖一张。5 张图都是 1120×728，拖进来后纵向排开即可。

### 几点预期管理

- **字体**：Figma 里要自己选 `PingFang SC`（macOS 自带，Figma 网页版能读到系统字体）。
  字体不对时行宽会变，中文尤其明显。
- **这是「静态高保真图」，不是可点击原型**。SVG 里没有页面间的跳转关系。
  要在 Figma 里做点击跳转，得用 Figma 自己的 Prototype 功能连（拖箭头连线），
  那部分是在 Figma 里完成的，不是文件里带的。
- 图层名继承自 CSS 类名（`.card.is-active` 这种），**看得出结构，但不好看**。嫌乱可以自己改。

## 已知缺陷

两类，都是**浏览器自己画的东西，DOM 里没有节点**，任何导出方式都拿不到：

| 缺什么                         | 在哪                              | 影响               |
| ------------------------------ | --------------------------------- | ------------------ |
| `<select>` 右侧的下拉箭头      | `03-usage` 的「最近 24 小时」右侧 | 看着像普通输入框   |
| `<summary>` 左侧的展开三角 `▶` | `05-profile-modal` 的「高级」前面 | 看不出这块能展开   |

各一处，手工补一个三角形/箭头即可。除此之外，5 张图与真实截图逐张比对过，没有别的差异。

**一处故意的不同**：`05-profile-modal` 里 API Key 输入框，真实界面显示的是圆点，
导出时也是圆点 —— `input.value` 读出的是明文，原样带走会把 key 写进原型文件。
导出脚本里按值长还原成等长圆点。

## 怎么重新生成

改完界面（`src/renderer/**`）之后：

```bash
npm run build            # 必须先构建 —— dist/ 在 .gitignore 里，不构建就导的是旧界面
node scripts/export-svg.js
```

脚本会自己起一个**真实 Electron**（隔离的假 HOME，用 `mkdtemp` 造，不碰你真实的
`~/.claude/settings.json` 和 `~/.cc-nbproject/profiles.json`），用 CDP 把每个元素的
几何、颜色、字号、文案抓出来，再生成 SVG。

想同时更新对照用的 PNG：

```bash
node scripts/shots.js
```

两个脚本的假数据（`PROFILES`）是**各自复制的一份**，改一处记得改另一处。

### 验证生成物

别只看「生成成功」。用浏览器打开 SVG 看一眼，或者跟 `shots/` 里的 PNG 并排比：

```bash
open docs/prototype/svg/01-providers.svg
open docs/prototype/shots/01-providers.png
```

这次的教训是：`tsc` / lint / 单测全绿证明不了 SVG 画得对。上面这些缺陷
（折行被压成一行、滚动区内容越界叠到按钮上、明文 key、丢失的选中态竖条）
**全都是靠肉眼看图才发现的**。
